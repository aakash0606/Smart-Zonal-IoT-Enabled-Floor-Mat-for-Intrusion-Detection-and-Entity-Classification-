Common causes & quick fixes
  1. If you see PERMISSION_DENIED — open Firebase Console → Realtime Database → Rules. For testing paste: 
    { "rules": { ".read": true, ".write": false } }
    (Don't keep write:true in production.)
  2. If anonymous auth fails, enable Anonymous sign-in in Firebase Console → Authentication → Sign-in method → Anonymous (toggle ON).
  3. Make sure databaseURL exactly matches your database (copy from Firebase Console → Realtime Database → Data → URL). Region & format matter.
  4. If snapshot is empty, check your device code — maybe it writes under a child path like /devices/DEVICE_ID or /readings.
