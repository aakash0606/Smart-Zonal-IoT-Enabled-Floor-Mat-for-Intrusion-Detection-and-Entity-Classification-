About the Project

This Anti-Theft Flooring Mat integrates FSR and Piezo sensors with an ESP32 to monitor footsteps and vibrations. Data is classified using machine-learning techniques to distinguish between humans, pets, or other objects.

Uses: Ideal for museums, banks, data centers, or any high-security zone.

Advantages: Real-time detection, remote monitoring through Firebase, and quick alerts help prevent unauthorized access.
